## 2026-10-19：P2 浏览器验收冷启动与并发隔离修复

### 修复内容

`internal-packages/viewer-runtime/scripts/check-resource-readiness.mjs` 为每次运行创建独立临时目录，分别容纳 `browser-profile` 与 `vite-cache`，不复用仓库共享的 Vite 依赖缓存。按模式选择唯一浏览器入口，同时用于 `optimizeDeps.entries`、`transformRequest` 和 CDP 动态导入。服务器启动后先检查入口转换结果，再等待初始请求处理完成，准备阶段预算为 60 秒，随后才启动 Chromium。

服务器创建、准备和浏览器启动统一纳入清理范围；准备计时器在成功和失败时均取消，浏览器启动错误立即释放启动计时器。只有实际启动且尚未退出的浏览器才等待退出，避免无效路径的 spawn 错误导致清理悬挂。服务器关闭失败时仍会删除临时目录。原有参数、结果 JSON 和实际检查的失败语义保持不变，没有加入重试、固定等待或忽略过期依赖请求。
