2. **Viewer 分页契约**：`@easyink/plugin-api/viewer` 导出继承 core 的 `ViewerFragmentPaginator`，要求 `getRemainingContent`，并用于 `ViewerRenderer.fragmentPaginator`；core 独立接口仍允许省略该方法。Viewer 对 `canPaginate` 实际启用的分页器检查该方法，继续执行局部诊断、占位和清理。公开 emitted 声明消费夹具验证完整分页器通过、缺少计数方法拒绝，同时保留 core 无计数分页器的正向消费。`table-session.test.ts` 覆盖 JavaScript 遗漏方法、NaN/负数/小数/不安全整数、无进展、重复或外来片段身份、抛错，确认兄弟节点输出和失败资源只释放一次。
3. **文档示例验收**：README 检查读取当前文档系列的 `id`，作为 `docsSeries` 传给原生成器；保留 README 全文一致性断言和所有示例的 emitted 声明编译。物料开发指南同步说明手动重试和 Viewer 分页计数契约。
