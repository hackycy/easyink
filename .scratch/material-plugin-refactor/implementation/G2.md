# G2 实施记录：text 与 image 双宿主完整切片

2026-10-11。G2 当前实施聚焦 text/image 双宿主模型与 builtin 集合出口，未进入后继 Gate。

## S1–S2：共享模型与独立物料

- text/image 的 `MaterialModel` 由各自物料包唯一维护；Designer 与 Viewer 定义复用同一 model 实例。
- binding、condition、默认节点工厂与已有属性、palette、locale、AI 描述由物料包提供。
- image 默认节点沿用冻结 Schema 行为；共享测试固定 model、binding、condition 和 partial props 语义。

## S3：单一集合成员源

- `packages/builtin/src/collection-source.ts` 保存 all/basic 成员与稳定顺序。
- `packages/builtin/tsdown.config.ts` 在构建前把成员源生成四个静态 Designer/Viewer 入口；运行时不再通过集合工厂二次装配。
- Viewer chart 顺序沿用既有输出；basic 排除 signature 与 chart，none 仍为空集合。
- `collection-source.test.ts` 校验四个入口的成员、顺序和生成结果一致。

## 消费与失败语义

- 两端仅消费创建时传入的完整物料集合；未知节点原始字段保留，显示 `[Unknown: <type>]` 占位和 UNKNOWN_MATERIAL 诊断。Designer 对同组件的重复挂载去重。
- eager renderer 直接消费；lazy renderer 首次消费时加载并去重。Viewer 的已声明 loader 失败显示 `[Unavailable: <type>]` 和 MATERIAL_LOAD_ERROR，其余节点继续输出，下一次 render 可重试；任务失败/销毁/迟到资源清理由现有 Host 管理。
- 自定义 renderer 通过 ViewerMaterial/DesignerMaterial 声明接入，不改变框架 registry 或模型行为。

image partial props 的旧语义经 G0 快照核对仍为整份替换，已修正前 slice 引入的语义改变，不更新冻结快照。
