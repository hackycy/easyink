# G3 实施记录：Designer UI 与受控服务迁移

2026-10-11。G3 当前实现锁定 Designer UI 消费者与受控上下文，不进入后继 Gate。

## S1：固定 UI 消费者

- 工具栏扩展动作在内置操作之后展示；画布右键扩展动作使用独立分组。
- 工具栏和右键动作按 `order` 升序排序，省略值按 0 处理，同序保留声明顺序和跨扩展稳定性。
- 动作通过安装 owner 的受控 `DesignerContext` 直接回调；disabled predicate、同步/异步回调错误只影响对应动作，并进入 Designer diagnostics。
- 物料属性组件实际消费 `MaterialPropertiesContext`。默认 append；`replace-body` 只替换物料属性区域，通用几何、绑定、条件、可见性和编辑机制继续由宿主渲染。

## S2：受控上下文与生命周期

- 每次 UI 挂载创建独立的短生命周期 scope，挂载卸载或 Host 销毁时失效并逆序清理；迟到回调无法写回。
- 属性 context 绑定当前单选节点和编辑会话，只暴露只读查询、事务编辑与 `flushPendingEdits`；跨节点、选区切换、文档替换或锁定/隐藏节点的写入被拒绝。
- 业务 props 的 `context` 字段被宿主保留，组件只能通过宿主注入 context 获取服务。
- Designer overlay 使用每实例实际 DOM 根和稳定 contribution key，未使用全局 overlay selector；局部渲染错误显示局部状态并记录诊断。

## S3：Assistant 与实例隔离

- Assistant 的面板状态和受控命令仍按 Designer 安装实例管理；UI mount 使用独立 context，按钮与面板通过命令保持联动。
- 两个 Designer 实例各自持有 locale、selection、Teleport 根和 UI scope；销毁一个实例不影响另一个实例。

## Evidence

- 定向 UI/生命周期测试覆盖工具栏、右键、属性 append/replace-body、权限、撤销、双实例 overlay、局部失败、卸载和迟到写入。
- Repository 验证以 G3 runbook 最新 `D1-D3`、`R1-R4` 结果为准；本记录不宣称 Gate 已通过。
