## S3a–S3b：内部物料消费者与受控上下文

本轮在 Designer/Viewer 包内新增框架内部消费者，尚未导出新的公共宿主创建 API，也未连入旧 Store/ViewerRuntime。未迁移业务继续使用既有路径；没有旧 API 转发到新 Host。下面的测试只证明这些独立切片，不证明 D1/D3 或 E1/E2 已满足。
