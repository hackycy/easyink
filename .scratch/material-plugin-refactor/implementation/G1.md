## S1a：公共入口

- 新增 `packages/plugin-api`，通过 pnpm workspace 依赖 core/schema/shared/datasource，版本暂与现有开发工作区一致；本次不执行版本发布操作。
- root/material/designer/viewer/ui 分别构建为真实 exports。Vue 仅由 ui 类型入口引用，采用 optional peer；根和无 UI 子入口没有重导出 UI。
- 共享模型保存 type、createDefaultNode、binding、capabilities、condition/pageAware；完整 Designer/Viewer 物料强制 renderer 或受管 loader 二选一，locale/AI/properties/UI 允许缺省。
- Designer 查询返回深只读文档/节点/选区及物料描述，编辑复用 core 命令和同步 tx；文档替换、扩展数据、数据源、交互与命令分别声明。物料属性上下文限制到当前节点查询/tx/flushPendingEdits。没有完整 Store、service token 或任意 point 配置。
- Viewer 采用同步 render/measure/getRenderSize，lazy loader 与可选会话 prepare 允许 Promise；上下文提供目标 document、只读输入及 signal/onDispose。会话分页运行引用与实际调度尚待后续实现，不声称现有 core paginator 已迁移。

## S1b：真实消费夹具

`packages/plugin-api/src/test-fixtures` 覆盖模型、两端完整物料、lazy、会话声明、集合/none、独立 UI/命令、FunctionalComponent 与 defineComponent。各夹具从公开包 exports 导入；检查器同时执行 TypeScript 正负向检查、Vite JS 实际模块图和声明图检查。root/material/designer/viewer 均不含 Vue/宿主实现/Assistant；ui 验证真实 Vue 类型且拒绝宿主实现依赖。core/schema/shared/datasource 无插件反向 dependencies。

负向夹具覆盖缺少核心 renderer、renderer 与 loader 同时提供、Viewer 编辑/注册权限、只读输入/文档/选区、异步 render、renderer 重复 pageAware、命令参数/结果、两类组件 context 错配、业务 props 覆盖 context、未定义通用 UI slot。负向指令未发生预期类型错误会导致检查失败。

首轮独立检查器通过，但 happy-dom 下 Vitest 的 import.meta.url 不是 file URL，且 lint 发现导入排序及空表达式；已修正脚本定位及夹具表达式后复验通过，不删除负向检查。
